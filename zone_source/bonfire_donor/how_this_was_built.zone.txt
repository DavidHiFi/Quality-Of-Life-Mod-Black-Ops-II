🛑 THE IMAGE HEADER IN HERE IS NOT ENOUGH. A T6 fastfile never stores pixels. The real texture is
   zone_assets\images\zom_icon_bonfire.iwi, converted from Black Ops 1's own
   F:\SteamLibrary\...\Call of Duty Black Ops\raw\images\zom_icon_bonfire.iwi:
       ImageConverter.exe --t5 zom_icon_bonfire.iwi      (T5 v13 .iwi -> .dds)
       ImageConverter.exe --t6 zom_icon_bonfire.dds      (.dds -> T6 v27 .iwi)
   Result 1,456 B, header "IWi" v27, format 13 (DXT5), 32x32 - the same shape as every other .iwi
   this project ships. A raw file in zone_assets\ BEATS every --load, so the header the Linker
   writes is built from THIS file and cannot disagree with the pixels mod.iwd serves.

Why a donor and not a --load of zm_pentagon.ff in build_ff.bat: the stock Linker cannot read the
   DLC5 zone, and a full load of a 60 MB map zone into every mod build would shadow shared names.
   The donor is tiny and is loaded LAST, so it can only supply names nothing above it offers.
